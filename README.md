## 一、VPN 协议怎么选（2026 现状）

如果你准备自己买一台海外 VPS 搭建个人 VPN，**千万不要照着五六年前的老教程去装裸奔 SS/SSR 了**，基本活不过几天。目前（2026 年）个人自建主流、抗封锁效果比较好的方案主要是下面几种：

| 协议方案 | 特点与适用场景 | 抗封锁能力 | 搭建难度 | 推荐度 |
| --- | --- | --- | --- | --- |
| **VLESS + Reality** | 无需自备域名和证书，伪装成正常 HTTPS 流量，目前综合最稳 | ⭐⭐⭐⭐⭐ | 简单 | 强烈推荐 |
| **Hysteria2** | 基于 QUIC/UDP，丢包严重或晚高峰线路差的 VPS 提速非常明显 | ⭐⭐⭐⭐ | 简单 | 强烈推荐 |
| **V2Ray / Xray (WS+TLS)** | 可配合 CDN（如 Cloudflare）救活被墙 IP，适合做备用线路 | ⭐⭐⭐⭐ | 中等 | 推荐备用 |
| **Trojan** | 伪装成标准 HTTPS 网站流量，需要准备一个域名 | ⭐⭐⭐⭐ | 中等 | 适合有域名用户 |
| **Shadowsocks (2022)** | 轻量、延迟低，但裸协议直连容易被精准识别，一般建议配合中转使用 | ⭐⭐⭐ | 简单 | 按需选择 |

### 自建前需要准备什么？
1. **一台海外 VPS**：常见地区选日本、新加坡、美国西海岸（洛杉矶/圣何塞）或香港；系统建议 **Debian 12** 或 **Ubuntu 22.04/24.04**。

## 三、全平台 VPN 客户端推荐

选客户端的核心原则只有一个：**用开源、持续维护的客户端，别在来路不明的网站下“破解版”**。

- **Windows / macOS / Linux**：优先推荐 `Clash Verge Rev`、`v2rayN`（Win/macOS/Linux）、`FlClash`
- **iOS / iPadOS**：`Shadowrocket`（小火箭，美区 App Store 付费）、`Stash`、`Quantumult X`
- **Android**：`Clash Meta for Android`、`v2rayNG`、`FlClash`、`Nekobox`

详细下载渠道和导入订阅步骤整理在：[全平台客户端配置指南](./docs/clients.md)。

## 四、自建 VPN 还是直接用现成 VPN？（实话实说）

我自己从最早搭 Shadowsocks 到现在用 Reality / Hysteria2，前前后后折腾了五六年。说句实在话，如果你不是为了学 Linux 运维，**纯自己买 VPS 搭 VPN 其实有几个很现实的痛点**：

1. **隐性成本并不低**：便宜的普通线路 VPS 虽然 2–3 美元/月就能买到，但晚高峰（20:00–23:30）跨网丢包非常严重，看个 1080P 都卡；想买 CN2 GIA / 优质回国线路，一台机器往往要 30–60 元/月以上。
2. **IP 被封和解锁麻烦**：一旦 IP 被拦截，换 IP 要额外花钱；而且很多机房的原生 IP 都被 OpenAI / ChatGPT、Netflix、Disney+ 拉黑了，自己搞分流解锁很费精力。
3. **维护耗时**：系统更新、证书续期、端口被封排查，工作忙的时候真的不想折腾。

所以我现在的实际用法是：**手里留一台便宜 VPS 跑 VLESS-Reality 当备用，日常主力直接用现成的机场 / VPN 服务**，省下来的时间干点别的更划算。

## 六、VPN 新手常见踩坑与避坑建议

1. **不要迷信“永久免费 VPN”**：带宽和服务器都是真金白银的成本，所谓永久免费要么限速到打不开网页，要么拿你的流量和隐私变现，账号密码甚至有泄露风险。
2. **注意分流规则（Rule 模式）**：日常使用建议把客户端开在「规则模式（Rule）」，国内网站直连、海外流量走代理，既不浪费流量也不会拖慢国内 App 速度。
3. **尽量避开敏感端口**：自建服务如果用 443 以外的端口，建议避开常见高危特征端口，优先用 `443` 搭配 Reality / TLS。
4. **多备一条退路**：无论是自建还是买现成服务，都建议手机和电脑里留一个备用方案，防止特殊时期主力线路波动时彻底断联。
